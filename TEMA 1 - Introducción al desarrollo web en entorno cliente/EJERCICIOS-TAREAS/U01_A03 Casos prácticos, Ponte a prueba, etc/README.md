# Práctica U01_A03 Casos prácticos, Ponte a prueba, etc...

## Descripción
Este proyecto contiene dos ejercicios prácticos relacionados con el entorno de desarrollo web:

- **Instalación y uso de NodeJS** mediante la creación y ejecución de un archivo `presentación.js`.
- **Edición de código HTML con Emmet** en Visual Studio Code, creando un archivo `pruebaEmmet.html`.

El objetivo es aprender a ejecutar en JavaScript desde la consola usando NodeJS y a generar estructuras HTML de forma rápida con Emmet.

## Contenido del archivo
En el proyecto se pueden encontrar los siguientes apartados:

- **Ejercicio 1 - NodeJS**
    - Instalación del entorno en el sistema operativo.
    - Creación del archivo `presentacion.js` con el nombre y apellidos en la salida por consola.
    - Ejecución del script en consola mediante el comando `node presentacion.js`.

- **Ejercicio 2 - Emmet en Visual Studio Code**
    - Creación del archivo `pruebaEmmet.html`.
    - Uso de Emmet para expandir abreviatura HTML (ejemplo: `div.contenedor>h1+p`).
    - Inclusión de nombre y fecha de realización en comentarios y en el contenido visible de la página.
    - Capturas mostrando el proceso en el editor y el resultado final en el navegador.

## Cómo visualizarlo
1. **NodeJS**
    - Descargar NodeJS desde la página oficial (versión LTS recomendada).
    - Guardar el archivo `presentacion.js` en una carpeta del sistema.
    - Abrir la consola y situarse en la ruta del archivo (muy importante esto último).
    - Ejecutar el comando:
    ```
    node presentacion.js
    ```
    - Se mostrará en la consola el mensaje con nombre y apellidos del autor.

2. **Emmet en Visual Studio Code**
    - Abrir VS Code y crear el archivo `pruebaEmmet.html`.
    - Escribir una abreviatura, por ejemplo:
    ```
    div.contenedor>h1{Hola}+p{Este archivo fue creado con Emmet}+footer>p{Autor: Mario Segura Abad}
    ```
    - Pulsar **TAB** para expandir automáticamente la estructura HTML.
    - Guardar el aarchivo y abrirlo en un navegador para visualizar el resultado.

## Objetivo de la práctica
- Instalar y utilizar NodeJS como entorno de ejecución de JavaScript.
- Familiarizarse con la ejecución de programas desde la consola.
- Descubrir la utilidad de Emmet como extensión para la escritura rápida de HTML.
- Practicar la documentación de proyectos incluyendo **nombre y fecha** en todos los archivos.
- Afianzar la importancia de las herramientas que facilitan el trabajo en el desarrollo web.

## Conclusión
Con la práctica realizada he conseguido aprender a instalar NodeJS, comprobar su funcionamiento y ejecutar un programa básico en JavaScript.
También hemos descubierto cómo Emmet puede ayudarnos a escribir código HTML de forma más rápida, utilizando abeviaturas parecidas a selectores CSS.
Ambas herramientas resultan muy útiles para optimizar el trabajo en proyectos reales y permiten ganar seguridad en el entorno de desarrollo.
