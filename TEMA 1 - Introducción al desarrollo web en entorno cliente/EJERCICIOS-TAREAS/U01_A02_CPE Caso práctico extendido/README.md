# Practica DWEC_U01_TEO_z_CPE - Unidad 01

## Descripción del proyecto
Este proyecto contiene un documento en formato **Markdown** (`DWEC_U01_TEO_z_CPE.md`) que recoge ejemplos prácticos de sintaxis. El objetivo es familiarizarse con el uso de Markdown para estructurar y dar formato a documentos de forma clara y profesional.

## Contenido del archivo
En el documento se pueden encontrar los siguientes ejemplos:

- **Encabezados** de nivel 1 y 2.
- **Párrafos** con texto normal, **negrita**, *cursiva* y ~~tachado~~ .
- **Bloques de código** en distintos lenguajes:
    1. HTML
    2. JavaScript
- **Listas**
    1. Desordenadas.
    2. Ordenadas.
- **Imágenes**: ejemplo con una imagen alojada en Wikimedia Commons.
- **Enlaces**: ejemplo de un enlace externo (Google).
- **Citas**: ejemplo de cita con la "Ley de Mosher de la Ingeniería de Software".

## Cómo visualizarlo
1. Descargar o clonar el repositorioi/proyecto.
2. Abrir el archivo `DWEC_U01_TEO_z_CPE.md` en:
    - Un editor compatible con Markdown (VS Code, Atom, etc.).
    - O un visor online Markdown.
3. Explorar cada apartado para ver cómo se renderiza el formato.

## Objetivo de la práctica
- Conocer la sintaxis básica de Markdown.
- Aprender a estructurar documentación técnica.
- Prepararse para crear archivos `README.md` en futuros proyectos.
