# Práctica DWEC - Unidad 2

## ¿Qué se ha hecho?
- Se ha creado un objeto llamado `Gasto` que representa cada gasto registrado por el usuario.
- Este objeto incluye propiedades como:
    - `descripcion`
    - `cantidad`
    - `fecha`
    - `categoria`
- Se han definido métodos como `mostrar()` para visualizar el gasto en el navegador.
- Se ha probado el objeto en varios scripts, incluyendo su integración en un listado de gastos y el cálculo el total gastado.
- Todo el código está comentado con nombre y fecha, y acompañado de pantallazos de ejecución.

## Ejercicios clave
- **Caso práctico**: creación del objeto `Gasto` con función constructora y prototipo.
- **"Ampliación" de dicho Caso práctico**: uso del objeto en una lista, recorrido con `forEach()` y cálculo de totales con `reduce`.

## Instalación

**Requisitos mínimos**:
**Editor de código**: en mi caso, Visual Studio Code.
- **Navegador web**: para ejecutar scripts con `document.write()` o `prompt()`.
- Node.js o la consola del navegador (F12): para ejecutar scripts con `console.log()` desde la terminal o consola.

## ¿Cómo se visualiza?

**En navegador**:
1. Abre el archivo `.html` con doble clic.
2. Introduce los datos si el script lo solicita.
3. Verás el resultado directamente en pantalla.

**En consola del navegador**:
1. Abre el navegador (en mi caso, __Google Chrome__).
2. Abre la consola (F12).
3. Verás los resultados en pantalla directamente, incluyendo los gastos y el total calculado.
