# Práctica DWEC - Unidad 2

## ¿Qué se ha hecho?
Se ha trabajado con programación funcional en JavaScript para recorrer, transformar y analizar arrays de objetos.
El apartado incluye tres bloques principales:
1. **Teoría del Apartado 5**: se han probado todos los scripts explicativos sobre métodos funcionales como `filter`, `map`, `find`, `reduce` y `forEach`.
2. **Scripts adjuntos**: se han ejecutado y documentado tres versiones de un script que muestra información estructurada por consola:
- Versión 1
- Versión 2
- Versión 3
3. **Caso práctico con array de coches**: se ha trabajado con un array de objetos que representa vehículos con marca, modelo y precio.
Se han realizado operaciones como filtrado por marca, búsqueda por precio, transformación del array con propiedades nuevas y cálculo del precio medio.

## Instalación y requisitos
No se necesita instalar ningún programa específico como tal, bastará con tener:
- **Editor de código compatible**: en mi caso VS Code.
- **Navegador web**: para ejecutar scripts con `console.log()` o integrarlos en una interfaz HTML
- Node.js (opcional): para ejecutar los scripts desde la terminal.

## Visualización

**En consola del navegador:**
1. Abre el navegador por omisión.
2. Abre la consola del navegador -> F12.
3. Pega el código del editor (habiéndolo copiado antes)
4. Verás los resultado por consola, incluyendo filtrados, transformaciones y cálculos.

**En navegador (opcional)**:
