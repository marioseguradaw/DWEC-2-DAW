# Práctica DWEC - Unidad 2

## Ejercicios incluidos
- **Código del Apartado 2 de teoría**: Se recopila y prueba todo el código mostrado en clase, incluyendo funciones tradicionales y llamadas con parámetros.

- **Scripts adjuntos**: Se ejecutan y explican los scripts proporcionados en la propia tarea, con pruebas de autoría y resultados por consola.

- **Caso práctico 2 - Función `media()` con parámetros variables**: Se crea una función que acepta cualquier cantidad de números y devuelve su media arimética.

- **Ponte a prueba 2 - Funciones flecha**: Se reescriben funciones tradicionales con sintaxis flecha, respetando el número de líneas internas.

## Instalación
Para ejecutar y visualizar los scripts, solo necesitas lo siguiente:
1. **Editor de código**<br>
El más recomendado, Visual Studio Code.
2. **Entorno de ejecución**
    - Para scripts con `console.log()`: Instala Node.js desde nodejs.org si quieres ejecutarlos en consola.
    - Para scripts HTML con `<script>`: No necesitas instalar nada. Basta con abrir el archivo `.html` en tu navegador (Chrome, Firefox, Edge, etc...).

## Cómo visualizarlo
**En consola (Node.js o consola del navegador):**
1. Abre la terminal.
2. Navega hasta la carpeta del proyecto.
3. Ejecuta el archivo con:
    `node nombreDelArchivo.js`

**En el navegador:**
1. Haz doble click en el archivo `.html`.
2. Introduce los datos si el script lo solicita (por ejemplo, número de filas).
3. Verás el resultado directamente en pantalla.
