# Práctica DWEC - Unidad 2

## ¿Qué se ha hecho?
- Se ha creado una clase base llamada `Animal` con propiedades `nombre` y `edad`, y un método `comer()` que imprime un mensaje en consola.
- Se ha creado una clase hija llamada `Perro` que hereda de `Animal`, añade la propiedad `raza` y el método `ladrar()`.
- Se ha instanciado un objeto `miPerro` con valores personalizados y se han probado absolutamente todos los métodos y propiedades.
- Todo el código está documentado con nombre y fecha, y acompañado de pantallazos de ejecución como prueba de autoría.

## Instalación

**Requisitos mínimos**:
- **Editor de código**: en mi caso, Visual Studio Code.
- **Navegador web**: para ejecutar scripts con `document.write()` o `prompt()`.
- Node.js o la consola del navegador (F12): para ejecutar scripts con `console.log()` desde la terminal o consola.

## ¿Cómo se visualiza?

**En navegador**:
1. Abre el archivo `.js` con doble clic.
2. Introduce los datos si el script lo solicita.
3. Verás los resultados en pantalla directamente.

**En consola del navegador**
1. Abre la consola con F12
2. Copia el código hecho en VS Code y pégalo directamente en la consola del navegador.
3. Pulsa la tecla **Enter**.
4. Verás los mensajes en consola confirmando que los métodos funcionan correctamente.
