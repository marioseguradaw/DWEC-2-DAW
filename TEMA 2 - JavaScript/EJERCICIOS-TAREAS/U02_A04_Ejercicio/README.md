# Práctica DWEC - Unidad 2

## ¿Qué se ha hecho?
Se han desarrollado dos ejercicios prácticos centrados en el uso de temporizadores y eventos en JavaScript:
1. **Cronómetro funcional** con horas, minutos, segundos y milisegundos. Incluye botones para:
    - **Arrancar**
    - **Parar**
    - **Continuar**
    - **Reiniciar**

Todo el código está comentado con nombre y fecha, y acompañado de pantallos de ejecución como prueba de autoría.

**Ejercicio clave**
- **Caso práctico**: cronómetro con control de botones y actualización en tiempo real usando las funciones `setInterval()` y `clearInterval()`.

## Instalación y requisitos
No se necesita instalar ningún programa específico como tal, bastará con tener:
- **Editor de código compatible**: en mi caso, VS Code.
- **Navegador web**: para ejecutar scrpits con HTML, JavaScript y elementos DOM, como es el caso.
- **Servidor local (totalmente opcional)**: solo si se desea evitar restricciones de seguridad al cargar archivos, que no es nuestro caso en este ejercicio en concreto.

## Cómo se visualiza

**En navegador**
1. Guarda el archivo `.html` y `.js` en la misma carpeta.
2. Abre el archivo `.html` usando (si está instalada) la extensión "Go Live", al final es lo más cómodo, directamente nada más pincharle se abre.
3. El cronómetro se mostrará en pantalla junto con los botones de control junto con el nombre del autor y fecha.
