# Práctica DWEC - Unidad 2

## Descripción
Este proyecto contiene varios ejercicios prácticos relacionados con el **Apartado 1 de la**
**teoría de JavaScript**, centrados en la creación de figuras con texto mediante bucles.
El objetivo principal es aplicar estructuras de control como bucles y condicionales, validar
entradas del usuario y mostrar resultados en consola de la página web.

Se han desarrollado dos versiones de un script que genera un rombo de asteriscos, con
número de filas configurable por el usuario. La primera versión utiliza bucles
tradicionales, mientras que la segunda emplea la función `repeat()` para construir el
patrón de forma más concisa. Además, se ha trabajado la documentación técnica del
proyecto, incluyendo comentarios identificativos, capturas de pantalla y estructura clara
en todos los apartados.

## Contenido del archivo
El proyecto se pueden encontrar los siguientes apartados:
- **Código del Rombo configurable**:
  Se han implementado dos scripts en JavaScript que generan un rombo en
  consola. El número de filas es introducido por el usuario, validando que sea impar
  y mayor o igual a tres. Cada incluye comentarios con el nombre del autor y la
  fecha de realización.

- **Interacción con funciones y bucles**:
  El primer script constituye el rombo utilizando bucles y la función `padStart()`
  para alinear los asteriscos. Se divide en dos partes: la superior y la inferior del
  rombo. Se han añadido capturas de pantalla que muestran la ejecución correcta
  en consola.

- **2ª versión con repeat()**:
  El segundo script utiliza `repeat()` para generar los espacios, simplificando el
  código y mejorando la legibilidad. El resultado visual es el mismo, pero con una
  implementación más moderna. Se han documentado los resultados con capturas
  de pantalla y comentarios.

- **Documentación técnica**:
  Se ha generado un documento PDF que incluye portada (Anexo 2), desarrollo por
  ejercicios, conclusión y capturas de pantalla. Todo el contenido estará justificado
  (Ctrl + J), cumpliendo con los requisitos del Anexo 1 – Instrucciones de entrega.

## Cómo visualizarlo
Para visualizar y ejecutar correctamente el proyecto, se deben seguir los siguientes pasos:
1. Crear el o los archivos (en este caso) en un editor de código compatible, en mi caso, VS Code.
2. Abrir dichos archivos `.html` en el editor.
3. Ejecutar los programas directamente en el navegador (abriendo la consola con F12):
    - Abrir cada archivo HTML para ver el resultado del rombo generado.
    - Introducir un número impar mayor o igual a 3 cuando se solicite.
4. Revisar las capturas de ejecución incluidas en la carpeta correspondiente, que muestran los resultados en pantalla junto con la prueba de autoría.
5. Consultar el documento PDF para entender el desarrollo completo del caso práctico y la estructura del proyecto.

## Objetivos de la práctica
Los objetivos principales de esta práctica son:
- Aplicar estructuras de control como bucles y condicionales en JavaScript.
- Validar entradas del usuario para asegurar datos correctos.
- Comparar dos enfoques distintos para construir patrones visuales.
- Documentar correctamente cada ejercicio, incluyendo autoría y capturas de pantalla.
- Familiarizarse con la creación de documentación técnica en formato Markdown y PDF.
- Aplicar buenas prácticas de programación, como el uso de comentarios identificativos.
- “Reflexionar” sobre la importancia de validar datos y presentar resultados de forma clara.

## Conclusión
Este proyecto ha permitido aplicar estructuras de control como bucles y condicionales en JavaScript, además de validar entradas del usuario y mostrar resultados en una página web.
Gracias a los dos enfoques utilizados –uno con bucles tradicionales y otro con la función repeat()— se ha reforzado la lógica de programación y la capacidad de generar patrones visuales dinámicos.
La práctica también me ha servido para mejorar la organización del código, el uso de comentarios identificativos y la documentación técnica del trabajo.
