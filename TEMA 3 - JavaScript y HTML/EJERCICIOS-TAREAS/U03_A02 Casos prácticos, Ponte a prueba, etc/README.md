# Práctica DWEC - Apartado 2  Unidad 3

## Ejercicios clave
- **Caso práctico 2 - Objetos manejadores de eventos**
    - Se trabaja con un array de objetos "chiste".
    - Se genera dinámicamente un `<div>` para cada chiste con un botón **Ver respuesta**.
    - Al pulsar el botón, se mostrará mediante un `alert`.

- **Ponte a prueba 2 - Delegación de eventos**
    - Se dispone de una rejilla de celdas (`<div class="celda">`).
    - Al hacer click sobre una celda, se activa o desactiva la clase `activa`.
    - Se utiliza **delegación de eventos**: el manejador se añade al contenedor (`#rejilla`) en lugar de a cada celda individual.
    - Se evita que el evento afecte al contenedor si se pulsa fuera de las celdas.

## Instalación y requisitos
No hace falta instalar nada como tal, bastará con tener:
- **Editor de código compatible**: en mi caso VS Code.
- **Navegador web**: en mi caso, el Chrome.

## Visualización

**En navegador**:
1. Guardar los archivos `.html` y `.js` en la raíz del proyecto.
2. Abrir el archivo `.html` con doble click.
3. **Caso Práctico 2**: pulsar los botones **Ver respuesta** para comprobar que se muestren los chistes.
4. **Ponte a Prueba 2**: hacer click sobre las celdas de la rejilla para activar o desactivar su estado.
5. Revisar la consola del navegador (F12 --> Consola) para verificar mensajes de prueba de autoría.
